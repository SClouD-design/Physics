Công cụ chạy hoàn toàn trên máy bạn. Bạn dán hoặc tải lên một giáo án chưa tích hợp năng lực số, chọn khối, rồi để AI cài các mã năng lực số vào đúng từng hoạt động theo khung 5512 — cùng phần giải thích rõ những gì đã thêm. Cuối cùng tải về file Word.

1

Kết nối API Gemini

Chưa có API key

Bạn dùng API key Gemini của riêng mình. Key chỉ nằm trên máy này và chỉ gửi thẳng tới Google — không lưu ở đâu khác.

▸ Cách lấy API key Gemini miễn phí (mất ~1 phút)
  1. Mở aistudio.google.com/apikey và đăng nhập tài khoản Google.
  2. Bấm Create API key (hoặc Get API key).
  3. Chọn/ tạo một dự án khi được hỏi, rồi bấm tạo key.
  4. Sao chép chuỗi key (bắt đầu bằng AIza…).
  5. Dán vào ô bên dưới. Gói miễn phí đủ để thử nghiệm (có giới hạn số lượt/phút).
 · Xóa key đã lưu
Nếu báo lỗi model không tồn tại, hãy chọn model khác.
2

Đưa giáo án vào

Tải file Word (.docx) hoặc dán trực tiếp nội dung giáo án gốc. Giữ nguyên cấu trúc bài để AI cài đúng chỗ.

Kéo–thả file .docx vào đây hoặc bấm để chọn
Đọc trực tiếp trong trình duyệt, không tải file lên máy chủ nào

3

Chọn cấp học

Bạn chỉ cần chọn cấp học — công cụ tự nhận diện môn và tự cài tất cả năng lực số phù hợp vào toàn bộ giáo án. THCS dùng mã TC2 (Bậc 4), THPT dùng mã NC1 (Bậc 5).

▸ Khung Năng lực số dùng trong công cụ (tham khảo)
Cách đọc mã: [Miền].[Năng lực thành phần][Trình độ][Bậc][a/b/c…]
Trình độ: CB Cơ bản (Tiểu học)   TC Trung cấp (THCS)   NC Nâng cao (THPT)   CS Chuyên sâu (CĐ–ĐH)
Ví dụ 1.1.NC1b = Miền 1 › NL 1.1 (tìm kiếm & lọc) › Nâng cao/Bậc 5 › mô tả b = “Áp dụng kỹ thuật tìm kiếm để lấy dữ liệu, thông tin, nội dung số”.
Công cụ hỗ trợ soạn giáo án theo Chương trình GDPT 2018 và Khung năng lực số cho người học (Thông tư 02/2025/TT-BGDĐT). AI có thể sai sót — giáo viên cần rà soát trước khi sử dụng.
